# Treppan Fragrance — The Royal Kuwaiti House of Fragrance (Est. 53)

A luxury frontend-only demo website for **Treppan Fragrance** built with React 18, TypeScript, Vite, and Tailwind CSS.

## Features

- **Luxury Botanical Scroll Stage**: 450vh scroll-driven experience with elliptical clip-path reveal and 6-flacon rotating orbit carousel.
- **Full-Bleed Editorial Hero Banner**: Flowing royal silk and gold backdrop with feather-blended signature flacons, Arabic calligraphy, and interactive notes inspector.
- **Dynamic 3-Tier Luxury Theme System**: Seamless client-side switching between **Royal Alabaster** (Light), **Obsidian Noir** (Dark), and **Imperial Sand** (Warm Amber).
- **Haute Parfumerie Catalog**: 5-category filterable showcase of 100% alcohol-free Aqua Parfums, pure Dehenal Oud oils, and Himalayan Kasturi musk attars.
- **Olfactory Pyramid Modal**: 3-tier note breakdown (Top, Heart, Base) with molecular sillage specifications.
- **VIP Concierge Integration**: One-click WhatsApp concierge enquiries with pre-filled fragrance context (zero pricing across the entire site).
- **Aviation Heritage**: Featured editorial on Treppan's in-flight partnership aboard Jazeera Airways.

## Tech Stack

- **Framework**: React 18 (TypeScript)
- **Bundler**: Vite 6
- **Styling**: Tailwind CSS 3 with CSS Custom Properties for theme tokens
- **Icons**: Lucide React

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```

## Deployment

Configured for one-click deployment on [Vercel](https://vercel.com) via `vercel.json` with SPA rewrites.
